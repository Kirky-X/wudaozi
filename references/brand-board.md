# Brand Board Template — 品牌规范板 / Logo 体系 / Identity Deck

> 用户要「品牌规范板 / brand guideline board / logo 体系 / identity deck / 品牌视觉墙」这类**单张多面板品牌系统图**时，用本文档组装 prompt。与 `prompt-template.md` 的关系：品牌板 = 7 维公式在品牌领域的**预设包**——Subject 变成「品牌策略 + Logo 概念」，其余维度变成板面系统参数。
>
> 结构吸收自 [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) 的 brandkit（MIT）；本文全部措辞为本仓库自著。取代此前对部署目录外部 `brandkit` skill 的路由。

## 触发词条

用户说「品牌规范板 / brand board / 品牌视觉系统 / logo 提案 / identity deck / 一张图看懂品牌」→ 走本文档。区别于：单张 logo 图（直接 7 维公式即可）；矢量 logo 文件与图标资产（→ xizhi）；项目 IP 形象（→ `character-sheet-workflow.md`）。

## 七维 → 品牌板预设映射

| 7 维 | 品牌板取值 | 默认 |
| --- | --- | --- |
| 1. Subject | 品牌名 + 核心隐喻 + Logo 概念（见「策略先行」） | 必填，向用户确认 |
| 2. Action/Expression | 板面叙事节奏：安静 → 功能 → 情绪 → 技术 → 氛围 → 细节，不允许每格同响 | 有节奏 |
| 3. Background/Environment | 深炭/纸张画布 + 强 gutter 演示网格 + 大留白 | 深炭起手 |
| 4. Composition/Perspective | 面板系统（见下），默认 `3×3`，画幅 4:3 或 16:10 | 3×3 |
| 5. Lighting | 视觉模式（8 选 1）定整体氛围 | 按品类选 |
| 6. Style/Medium | premium identity deck / 设计师提案板 / brand-system case study | 固定 |
| 7. Quality/Detail | 高级细节语言：页码、对齐标记、construction line、halftone/grain 纹理——点到为止 | 少而准 |

## 策略先行（Subject 维度的展开）

生成前先推断品牌策略，视觉系统必须长在意义上，符号不许随机选：

| 品类 | 核心想法 | 可选符号逻辑 |
| --- | --- | --- |
| 开发者工具 | 构建、速度、精确、控制 | 光标、框架、闪电、脚手架、网格 |
| AI 助手 | 委托、智能、清晰 | 火花、轨道、信号、路径、节点 |
| 安全 | 保护、警觉、边界 | 盾、眼、封印、受护核心 |
| 游戏/博弈 | 机遇、奖励、张力、速度 | 骰子、宝石、卡牌、奖杯 |
| 语音 AI | 声音、节奏、指令、流动 | 波形、麦克风、声球、语音路径 |
| 合规 | 信任、秩序、规则 | 封印、徽章、文档、盾 |
| 无人机/机器人 | 飞行、控制、视觉、任务 | 翼、猫头鹰、准星、航径 |
| 奢侈/编辑 | 品味、材质、仪式、克制 | 花押、封印、纸张、压凹、标记 |
| 效率工具 | 专注、推进、清晰 | 路径、勾、方块、日历、光 |

同时明确：受众、情感承诺、文化位置、品牌**要避开什么**。

## Logo 五法（Subject 的核心，最多组合两种）

1. **字首 + 隐喻**：品牌首字母与隐喻融合（K+风筝/框架、S+声波）；用负空间、切口、折叠、几何，不做无聊的字母图标。
2. **产品动作符号化**：把产品主动作抽象成符号（build→框架/脚手架、protect→盾/边界、speak→波形/麦克风）；要 premium 的抽象，不要直白图解。
3. **隐喻融合**：两个有意义的概念融成一个简化标记（猫头鹰+无人机视觉、盾+山、骰子+游戏经济）；融合要微妙可读。
4. **负空间**：用空缺制造智性——隐藏箭头、受护中心、镂空字首、交叉成形的眼；负空间要干净利落。
5. **构造几何**：圆、对角切、网格、模块块、轨道线、准星、测量线条——其中一格可展示构造逻辑。

Logo 标准一句话：简单、可记、有象征、可缩放、可 ownable，能同时用在 icon/wordmark/badge/UI mark/pattern。禁：通用闪电、随机动物、假奢侈纹章、名人商标仿制、复杂堆叠、剪纸风、无意义闪光。

## 面板系统（Composition 维度的展开）

**3×3 默认九宫**：① Logo 封面（大标+字标，强留白）② Logo 构造（网格/几何/负空间逻辑，说明标记为何存在）③ 数字应用（浏览器 chrome/app 头/终端/仪表盘碎片/app 图标）④ 品牌本质（一句 tagline，大字，稀疏）⑤ 色彩系统（色板/渐变条/色盘/材质芯片）⑥ 字体（大字样/字母行/主副字配对）⑦ 实体应用（卡片/徽章/海报/标签/包装样机）⑧ 图像方向（电影感风景/产品特写/halftone 海报/材质）⑨ 系统细节（UI 芯片/输入条/命令行/图标行/组件条/纹样）。

**2×3 六宫（deck 式）**：Logo/字标 → 浏览器或产品表面 → 命令/功能面板 → 氛围图 → 符号/构造/徽章 → 一句承诺。其他可选：2×2 紧凑概念板、1×3 横条、4×2 宽 contact sheet。

用户给了参考图时：提取节奏、网格、密度、字阶、色逻辑——对齐其**质量与节奏**，不抄内容与构图。

## 视觉模式（Lighting/Style 维度的展开，8 选 1）

| 模式 | 适用 | 视觉线索 | Logo 逻辑 |
| --- | --- | --- | --- |
| Dark Developer | 开发工具/infra/自动化 | 近黑面板、等宽字、命令行、prompt 条、青/蓝/珊瑚/柠 accent | 光标+框架、脚手架+字首 |
| Dark Operator | 业务/增长/销售工具 | 黑/暗红/琥珀、发光 UI 芯片、卡组、分段流 | 信号、路径、开关、回路 |
| Dark Nature | 战略/旅行/wellness/安静 SaaS | 深绿+柠 accent、雾景、暗编辑网格 | 路径、叶、月、地平线 |
| Dark Security | 安全/合规/监控 | 黑/藏青、盾形、雷达线、红蓝告警芯片 | 盾、猛禽、眼、受护核心 |
| Light Editorial | 法务/隐私/文档/信任 | 暖象牙、纸纹、衬线小标签、封印徽章 | 封印、文档、花押 |
| Luxury/Beauty | 美妆/时尚/酒店/高端服务 | 象牙/石头/浓咖、衬线字标、压凹、纸纹 | 花押、花瓣、容器、仪式物 |
| Voice | 语音 AI/聊天/音频 | 暗靛+丁香辉光、波形、麦克风、手机局部 | 波形+字首、声球、脉冲环 |
| Cultural | 音乐/创意工具/活动 | halftone、CRT 纹理、海报面板、大胆 accent | 定制字标、有态度的图标 |

## 文字与配色纪律（Quality 维度的展开）

- 文字极少量：品牌名、一句 tagline、一个 URL、一条命令、2-5 个节标签、短 UI 芯片。禁长段、假正文、密集菜单、lorem ipsum。
- tagline 短而具体（「Nothing random.」「Build better.」「On guard.」式），禁空泛企业口号与热词堆砌。
- 配色一盘棋：底色+主 accent+副 accent+中性色；accent 必须跨面板复现；一个 accent 可以扛起整套系统；禁随机彩虹、禁默认紫蓝 AI 辉光（除非模式匹配）。
- 图像与样机要 art-directed：电影感风景/halftone 云/暗调产品特写/材质纸底；样机是身份应用不是功能演示（禁全量假仪表盘、玻璃廉价样机、设备堆叠）。

## 反泛化清单

不许出现：随机漂浮图标、通用创业渐变、过度设计的 logo、无意义色块、凌乱拼贴、假 UI 微缩、前后不一致的 logo 变体、超量颜色、廉价荧光、模板化品牌板、PPT 感、无魂 SaaS 仪表盘。

## 生成前 checklist

- [ ] 7 维预设包每个维度都显式确认过吗（Subject 必须向用户确认）？
- [ ] 面板系统选型 + 视觉模式选型是否与品类匹配？
- [ ] Logo 用了五法之一且不超过两法组合？
- [ ] 文字量、tagline、配色纪律过审？反泛化清单逐条过一遍？
